관리자 콘솔

모델·화면이 쓰는 값의 정본은 서버입니다. 여기서 바꾼 값은 시뮬레이션·추천·화면 표기에 즉시 반영되고, 전부 사유와 함께 기록됩니다.

← 대시보드 시뮬레이션

관리자 인증

접근 토큰은 서버 .env 의 ADMIN_TOKEN 입니다. 서버에 설정돼 있지 않으면 관리자 기능 전체가 닫혀 있습니다.

배차 영향력 즉시 반영

시뮬레이션·추천이 요청 시점에 읽는 값입니다. 저장하면 다음 계산부터 바로 적용됩니다.

비용·예산 즉시 반영

단가를 바꾸면 추천 순위(비용 대비 효과)와 화면의 단가 표기가 함께 바뀝니다.

모델 상수 재계산 필요 · 잠김

격자 지표(D·S·MI)에 구워지는 값이라 재계산 경로가 오버라이드를 읽는 다음 단계에서 개방됩니다. 지금은 근거 열람만 됩니다.

기준선 상수 읽기 전용

바꾸려면 "새 기준선 발행"(재계산 + 재검증 + 문서 갱신)이 필요한 값들입니다. 현재 서버에 실제로 적용된 값을 보여줍니다.
